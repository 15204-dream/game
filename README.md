# 《糟糕！是心动鸭！》恋综模拟器游戏 - 项目说明文档

## 🎮 游戏概述

《糟糕！是心动鸭！》是一款融合真人秀恋综元素与角色扮演模拟的创新型互动叙事游戏。游戏提供**双模式玩法**：

- **嘉宾模式**：玩家作为第13位神秘嘉宾，与12位性格迥异的素人嘉宾共同生活21天，找到真爱或收获友情
- **导演模式**：玩家扮演节目导演，通过安排活动、制造话题、处理危机等手段，打造一档爆款恋综

## 🚀 快速开始

### 环境要求
- Unity 2022.3 LTS 或更高版本
- .NET Framework 4.7.2+
- C# 8.0+

### 安装步骤

1. **克隆或下载项目到本地**
2. **使用Unity打开项目**
   ```bash
   cd /workspace
   unity -openProject .
   ```

3. **配置API密钥**
   - 打开 `Assets/Scripts/Core/API/APIClient.cs`
   - 确认API密钥已配置：
   ```csharp
   private const string API_KEY = "sk-fe8fdf06158c44b5b6304a8e30dce5a8";
   ```

4. **运行游戏**
   - 打开主场景 `Scenes/MainMenu.unity`
   - 点击Play按钮运行

## 🎯 核心功能

### 1. 双模式系统
- ✅ 嘉宾模式：角色扮演、社交互动、感情线发展
- ✅ 导演模式：节目运营、热度管理、话题制造
- ✅ 模式切换：无缝切换，数据独立

### 2. AI对话引擎
- ✅ DeepSeek API集成
- ✅ 动态剧情生成
- ✅ 角色性格一致性
- ✅ 情感计算系统
- ✅ 内容过滤机制

### 3. 12位角色系统
**男嘉宾（6位）**：
- 冷冷（顾北辰）- 高冷禁欲
- 森森（林屿森）- 阳光暖男
- 琛哥（陆景琛）- 成熟稳重
- 小季（季淮序）- 艺术傲娇
- 洲洲（沈逸洲）- 自信健身博主
- 言深（傅言深）- 神秘腹黑

**女嘉宾（6位）**：
- 念念（苏念念）- 甜美可爱
- 晚宁（姜晚宁）- 知性干练
- 知意（夏知意）- 活泼八卦
- 星辰（顾星辰）- 浪漫内敛
- 幼薇（沈幼薇）- 邻家甜美
- 酒酒（温酒酒）- 酷飒御姐

### 4. 结局系统
**嘉宾模式**：6种主结局 + 12种角色结局 + 4种彩蛋结局
**导演模式**：6种节目等级（S/A/B/C/D/E）+ 6种导演成就

### 5. 任务系统
- 日常任务（每日刷新）
- 主线任务（阶段解锁）
- 角色专属任务（好感度触发）
- 成就任务（挑战解锁）

### 6. 商城系统
**嘉宾模式**：金币、钻石、心动值货币
**导演模式**：导演币、热搜券、公关点数

## 📖 使用指南

### 嘉宾模式玩法

1. **创建角色**
   - 输入昵称
   - 选择性别
   - 选择性格标签

2. **日常生活**
   - 与嘉宾互动
   - 参与集体活动
   - 完成日常任务

3. **感情发展**
   - 提升好感度
   - 触发角色专属剧情
   - 避开雷区

4. **最终告白**
   - 好感度达到90+
   - 完成专属任务线
   - 选择最终告白对象

### 导演模式玩法

1. **节目策划**
   - 查看嘉宾资料
   - 制定运营策略

2. **日常运营**
   - 安排节目活动（消耗行动点）
   - 发布话题营销
   - 私下谈话引导嘉宾

3. **危机处理**
   - 监控系统预警
   - 选择危机处理方案
   - 维护节目口碑

4. **完美收官**
   - 热度达到80+
   - 口碑保持75+
   - 达成A级以上结局
