# 糟糕！是心动鸭！- 恋综模拟器游戏 - 产品需求文档

## 概述
- **摘要**: 开发一款名为《糟糕！是心动鸭！》的恋综模拟器游戏，包含嘉宾模式和导演模式两种玩法，AI驱动对话生成，复古像素风画面。
- **目的**: 打造一款沉浸式恋爱综艺模拟游戏，让玩家体验恋综的浪漫与刺激。
- **目标用户**: 恋爱游戏爱好者、恋综观众、喜欢像素风游戏的玩家。

## 目标
- 完整实现嘉宾模式和导演模式两种玩法
- 实现12位嘉宾（6男6女）的详细人设和互动
- 集成DeepSeek兼容的AI对话引擎，实时生成对话
- 实现网状分支剧情网络和50+种结局
- 生成像素风立绘和场景插图（128x128像素，复古像素风）
- 实现任务系统、社交系统、商城系统、新手引导、数据统计面板等完整功能
- 使用方舟像素体字体
- 支持Web平台，后续可扩展到桌面应用
- 实现可选登录和云同步功能
- 单局游戏时长8+小时

## 非目标（范围外）
- 不开发移动端原生App（仅响应式Web）
- 不实现多人在线模式
- 不内置支付系统（商城用游戏内货币）
- 不做实时直播功能

## 背景与上下文
- 用户需求明确，要做一个完整的恋综模拟器
- 选择纯JavaScript + HTML5 Canvas技术栈，灵活性高
- 复古像素风类似《星露谷物语》，受众广泛
- AI对话是核心特色，使用DeepSeek兼容API

- **FR-2**: 导演模式 - 玩家扮演导演，安排活动管理热度
- **FR-3**: 12位嘉宾详细人设（6男6女）

- **FR-7**: 社交系统（好感度/关系网络/CP配对）
- **FR-8**: 商城系统
- **FR-9**: 新手引导系统
- **FR-10**: 数据统计面板
- **FR-11**: 存档系统（本地+可选云同步）

## 非功能需求
- **NFR-1**: 性能 - Web端流畅运行，支持主流浏览器
- **NFR-2**: 可访问性 - 响应式设计，适配不同屏幕
- **NFR-3**: 可维护性 - 代码模块化，易于扩展
- **NFR-4**: 数据安全 - API Key安全存储，用户数据加密

## 约束
- **技术**: 纯JavaScript + HTML5 Canvas，不使用框架
- **设计风格**: 复古像素风，128x128人物立绘
- **字体**: 方舟像素体
- **API**: DeepSeek兼容，使用指定API Key
- **平台**: Web优先，后续桌面

## 假设
- API Key有效且可正常使用
- 像素风资源可以通过AI生成或制作
- 目标用户对这种玩法有兴趣

## 验收标准

### AC-1: 核心玩法实现
- **给定**: 游戏启动
- **当**: 玩家选择嘉宾模式或导演模式
- **则**: 可以正常进入对应模式，开始游戏
- **验证**: programmatic
- **备注**: 两种模式都能正常启动和游玩

### AC-2: AI对话功能
- **给定**: 游戏运行中
- **当**: 玩家与嘉宾互动
- **则**: AI生成符合人设的对话
- **验证**: programmatic + human-judgment
- **备注**: 对话要自然，符合嘉宾性格

### AC-3: 12位嘉宾
- **给定**: 游戏中
- **当**: 查看嘉宾信息
- **则**: 12位嘉宾（6男6女）信息完整，立绘显示正常
- **验证**: programmatic + human-judgment

### AC-4: 多结局系统
- **给定**: 游戏进行
- **当**: 玩家完成游戏
- **则**: 根据选择达成对应结局，支持解锁50+种
- **验证**: programmatic

### AC-5: 像素风画面
- **给定**: 游戏画面
- **当**: 任意场景
- **则**: 复古像素风画面，人物立绘128x128，使用方舟像素体字体
- **验证**: human-judgment

### AC-6: 存档同步
- **给定**: 游戏中
- **当**: 玩家存档或读取
- **则**: 本地存储正常，可选云同步
- **验证**: programmatic
