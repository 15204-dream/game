# 《糟糕！是心动鸭！》恋综模拟器游戏设计规格

## 一、项目概述与愿景

### 1.1 项目背景

《糟糕！是心动鸭！》是一款融合真人秀恋综元素与角色扮演模拟的创新型互动叙事游戏。游戏提供**双模式玩法**，玩家可以选择：

- **嘉宾模式**：玩家作为第13位神秘嘉宾入驻"心动小屋"，与12位性格迥异的素人嘉宾共同生活21天，通过日常互动、任务挑战、深夜密室对话等环节解锁多样结局，找到真爱或收获友情。

- **导演模式**：玩家扮演节目导演，站在上帝视角俯瞰全局，通过安排嘉宾活动、设计节目环节、制造话题冲突、运营社交媒体等手段，打造一档爆款恋综，提高节目热度和收视率。

游戏以"心跳加速的小确幸"为核心情感基调，融入幽默吐槽与甜虐交织的叙事风格，呈现一段充满未知与心动的沉浸式体验。

### 1.2 核心特色

- **AI驱动的动态剧情**：基于DeepSeek API实现上下文感知的剧情生成，每位角色的对话和反应会根据玩家选择动态演化
- **真实社交模拟**：模拟真实恋综的社交博弈机制，包含好感度系统、嫉妒机制、阵营分化等
- **多维度角色塑造**：12位嘉宾拥有独立的性格特质、隐藏背景故事与心理创伤
- **双模式自由切换**：同一套角色数据，两种截然不同的游玩体验
- **开放式结局设计**：嘉宾模式6种主结局 + 12种角色个人结局 + 隐藏彩蛋结局；导演模式多种节目结局
- **节目运营策略**：导演模式引入热度系统、话题制造、危机公关等经营要素

## 二、恋综世界观设定

### 2.1 节目设定

**节目名称**：糟糕！是心动鸭！
**节目形式**：沉浸式恋爱真人秀
**录制周期**：21天（游戏内时间）
**录制地点**：心动小屋（海边别墅，含公共区域与独立房间）
**节目规则**：

- 每晚22:00进行"心动信箱"互选
- 每3天举行一次"约会选择"公开投票
- 每周设置主题任务挑战（户外竞技/才艺展示/真心话之夜等）
- 第21天为最终告白夜

### 2.2 心动小屋地图

| 区域 | 功能 | 触发事件类型 |
|------|------|-------------|
| 客厅 | 主要社交区域 | 日常闲聊、临时任务 |
| 厨房 | 烹饪互动 | 厨房协作、投喂好感 |
| 游泳池 | 户外休闲 | 泳池派对、单独邀约 |
| 天台花园 | 私密对话 | 深夜密谈、心动告白 |
| 健身房 | 共同运动 | 健身互动、体能任务 |
| 密室（解锁） | 私密空间 | 隐藏剧情、特殊约会 |

### 2.3 时间系统

| 时段 | 时间范围 | 可用行动（嘉宾模式） | 可用行动（导演模式） |
|------|----------|---------------------|---------------------|
| 清晨 | 06:00-09:00 | 晨跑、早餐互动 | 查看夜间数据、调整今日安排 |
| 上午 | 09:00-12:00 | 自由活动、房间剧情 | 节目策划、会议讨论 |
| 午间 | 12:00-14:00 | 午餐、日常任务 | 素材审核、热度监控 |
| 下午 | 14:00-18:00 | 主题活动、户外任务 | 现场调度、突发处理 |
| 傍晚 | 18:00-21:00 | 晚餐、厨房互动 | 嘉宾安抚、关系调整 |
| 夜晚 | 21:00-23:00 | 夜间活动、心动信箱 | 每日复盘、明日计划 |
| 深夜 | 23:00-02:00 | 隐藏剧情、密室互动 | 舆情监控、危机预警 |

## 五、导演模式：节目运营系统

### 5.1 导演模式概述

- 安排和设计节目活动
- 制定嘉宾配对策略
- 制造话题和冲突
- 处理突发危机
- 管理节目热度
- 与嘉宾进行一对一谈话引导

```python
        "model": "deepseek-chat",
        "messages": [
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_message}
        ],
        "temperature": 0.8,
        "max_tokens": 2048,
        "top_p": 0.9
    }
    
    response = requests.post(api_url, headers=headers, json=payload)
    result = json.loads(response.text)
    
    return json.loads(result['choices'][0]['message']['content'])
```
