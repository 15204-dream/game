# 《糟糕！是心动鸭！》恋综模拟器游戏设计规格

## 一、项目概述与愿景

### 1.1 项目背景
《糟糕！是心动鸭！》是一款融合真人秀恋综元素与角色扮演模拟的创新型互动叙事游戏。玩家将作为第13位神秘嘉宾入驻"心动小屋"，与12位性格迥异的素人嘉宾共同生活21天，通过日常互动、任务挑战、深夜密室对话等环节解锁多样结局。游戏以"心跳加速的小确幸"为核心情感基调，融入幽默吐槽与甜虐交织的叙事风格，呈现一段充满未知与心动的沉浸式恋爱体验。

### 1.2 核心特色
- **AI驱动的动态剧情**：基于DeepSeek API实现上下文感知的剧情生成，每位角色的对话和反应会根据玩家选择动态演化
- **真实社交模拟**：模拟真实恋综的社交博弈机制，包含好感度系统、嫉妒机制、阵营分化等
- **多维度角色塑造**：12位嘉宾拥有独立的性格特质、隐藏背景故事与心理创伤
- **开放式结局设计**：6种主结局 + 12种角色个人结局 + 隐藏彩蛋结局

## 二、恋综世界观设定

### 2.1 节目设定

**节目名称**：糟糕！是心动鸭！
**节目形式**：沉浸式恋爱真人秀
**录制周期**：21天（游戏内时间）
**录制地点**：心动小屋（海边别墅，含公共区域与独立房间）
**节目规则**：
- 每晚22:00进行"心动信箱"互选
- 每3天举行一次"约会选择"公开投票
- 每周设置主题任务挑战（户外竞技/才艺展示/真心话之夜等）
- 第21天为最终告白夜

```python
        "model": "deepseek-chat",
        "messages": [
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_message}
        ],
        "temperature": 0.8,
        "max_tokens": 2048,
        "top_p": 0.9
    }
    
    response = requests.post(api_url, headers=headers, json=payload)
    result = json.loads(response.text)
    
    return json.loads(result['choices'][0]['message']['content'])
```

#### 5.3.3 情感计算公式
```python
def calculate_emotion_change(
    base_emotion: float,
    action_type: str,
    character_traits: Dict,
    recent_interactions: List
) -> float:
    """
    情感变化计算
    - 基础变化：根据行动类型
    - 性格加成：根据角色性格特质
    - 近因效应：最近3次互动的加权平均
    """
    base_change = ACTION_EMOTION_MAP.get(action_type, 0)
    trait_modifier = sum(CHARACTER_TRAIT_BONUS.get(trait, 0) 
                         for trait in character_traits)
    recency_weight = sum(r * w for r, w in 
                         zip(recent_interactions[-3:], [0.5, 0.3, 0.2]))
    
    return base_emotion + base_change + trait_modifier + recency_weight
```

### 11.3 上下文记忆系统

```python
class ConversationMemory:
    """对话记忆系统 - 模拟人类记忆特性"""
    
    def __init__(self):
        self.short_term = []      # 短期记忆（当前对话）
        self.working_memory = []  # 工作记忆（最近3次对话）
        self.long_term = {}       # 长期记忆（角色重要事件）
        
    def add_interaction(self, dialogue: Dialogue):
        """添加对话到记忆"""
        # 提取关键信息
        key_info = self.extract_key_info(dialogue)
        
        # 更新各层级记忆
        self.short_term.append(key_info)
        self.working_memory.append(key_info)
        
        # 重要事件写入长期记忆
        if self.is_significant(key_info):
            self.long_term[key_info.timestamp] = key_info
        
        # 记忆衰减
        self.decay()
    
    def get_context_prompt(self) -> str:
        """生成上下文提示词"""
        # 整合长期记忆中的相关事件
        relevant_long_term = self.get_relevant_long_term()
        
        # 构建记忆摘要
        memory_prompt = f"""
        【角色关系背景】
        {relevant_long_term}
        
        【近期互动摘要】
        {self.working_memory}
        
        【当前对话】
        {self.short_term}
        """
        return memory_prompt
```

### 11.4 情感计算引擎

```python
class EmotionEngine:
    """情感计算引擎"""
    
    EMOTION_DIMENSIONS = [
        "喜悦", "悲伤", "愤怒", "恐惧", 
        "惊讶", "羞涩", "期待", "厌恶"
    ]
    
    def calculate_emotion(
        self,
        base_emotion: Dict[str, float],
        stimulus: EmotionStimulus,
        character: Character
    ) -> Dict[str, float]:
        """计算情感变化"""
        
        # 1. 基础情感响应
        emotion_change = self.get_stimulus_response(stimulus)
        
        # 2. 角色性格调节
        trait_modifiers = self.get_trait_modifiers(
            character.traits, 
            emotion_change
        )
        
        # 3. 关系亲密度调节
        intimacy_modifier = self.get_intimacy_modifier(
            character.relationship.friendship
        )
        
        # 4. 情境因素
        context_modifier = self.get_context_modifier(
            stimulus.context
        )
        
        # 5. 综合计算
        final_change = {
            dim: (emotion_change.get(dim, 0) * 
                  trait_modifiers.get(dim, 1.0) * 
                  intimacy_modifier * 
                  context_modifier)
            for dim in self.EMOTION_DIMENSIONS
        }
        
        return self.normalize(base_emotion, final_change)
    
    def get_trait_modifiers(
        self, 
        traits: List[str], 
        emotion_change: Dict
    ) -> Dict[str, float]:
        """性格特质的情感调节"""
        modifiers = {}
        
        if "傲娇" in traits:
            modifiers["羞涩"] = 1.5
            modifiers["喜悦"] = 0.7  # 压抑喜悦表达
        if "敏感" in traits:
            modifiers["惊讶"] = 1.3
            modifiers["悲伤"] = 1.2
        if "阳光" in traits:
            modifiers["喜悦"] = 1.2
            modifiers["悲伤"] = 0.8
            
        return modifiers
```
