# 《糟糕！是心动鸭！》恋综模拟器游戏 - 验收检查清单

## 检查清单使用说明

本检查清单用于验证游戏开发的各个模块是否符合设计规格。在进行阶段性验收时，逐项检查并标记完成状态。

---

## 核心系统检查

### 🔷 基础架构系统

- [ ] **项目结构规范**：项目文件夹结构清晰，符合开发规范（Assets/Scenes/Scripts/Data等目录正确创建）
- [ ] **数据持久化**：玩家数据能够正确保存到本地存储，并在下次启动时正确加载
- [ ] **数据迁移**：数据版本升级时能够正确迁移，不会丢失玩家进度
- [ ] **多平台兼容**：核心逻辑支持主流平台（Windows/Mac/iOS/Android）

### 🔷 角色系统

- [ ] **角色数据完整性**：12位角色数据全部配置正确，包含昵称、性格标签、职业、隐藏特质等所有字段
- [ ] **角色立绘显示**：所有角色的立绘图正确显示，包括正常状态和表情变化
- [ ] **角色性格一致性**：AI对话生成时角色性格保持一致，符合设定
- [ ] **角色状态切换**：角色在idle/talk/emote等状态间正确切换
- [ ] **角色动画流畅**：角色动作和表情动画播放流畅自然

## 社交系统检查

### 💕 好感度系统

- [ ] **情感动画反馈**：好感度变化时有适当的视觉/音效反馈
- [ ] **嫉妒机制生效**：与某角色互动过于频繁时，相关角色好感度正确下降

- [ ] **对话影响合理**：不同对话选项对好感度的影响符合设计预期
- [ ] **社交关系网络**：NPC之间的关系正确影响剧情发展
- [ ] **互动历史记录**：对话历史被正确记录并在后续对话中使用

### 💌 心动信箱

- [ ] **信箱界面正常**：心动信箱UI正确显示，可正常操作
- [ ] **写信功能完整**：玩家能够编写并发送信件
- [ ] **结果揭晓动画**：心动结果揭晓时动画和音效正确播放
- [ ] **规则验证正确**：信箱规则（如每日限制）正确执行

## AI对话引擎检查

### 🤖 API集成

- [ ] **API调用成功**：DeepSeek API能够正确调用并返回结果
- [ ] **请求参数正确**：API请求参数配置符合DeepSeek要求（model、temperature等）
- [ ] **API密钥安全**：API密钥正确存储，不在代码中硬编码暴露
- [ ] **错误处理完善**：API调用失败时能够优雅降级，不导致游戏崩溃
- [ ] **频率限制生效**：API调用频率限制正常工作，避免超出配额

### 💭 对话生成质量

- [ ] **角色性格一致**：生成的对话符合角色性格设定（冷冷的高冷、森森的阳光等）
- [ ] **上下文连贯**：多轮对话上下文连贯，不会重复或矛盾
- [ ] **情感表达丰富**：对话中包含适当的情感描写和内心独白
- [ ] **内容过滤有效**：敏感内容过滤正常工作，不生成不当内容
- [ ] **响应时间合理**：对话响应时间在可接受范围内（<3秒）

### 🧠 智能对话系统

- [ ] **状态机运转**：对话状态机在各种状态间正确转换
- [ ] **记忆系统有效**：角色能够记住之前的对话内容并在后续使用
- [ ] **情感计算准确**：角色情感变化符合互动情境
- [ ] **策略选择合理**：根据角色性格和关系选择合适的对话策略
- [ ] **离线对话可用**：在无网络时能够使用本地模板继续对话
