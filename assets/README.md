# 游戏资源目录

## 目录结构
- `fonts/` - 字体文件
- `images/characters/` - 角色立绘
- `images/ui/` - UI元素
- `images/backgrounds/` - 背景图片
- `audio/` - 音频文件

## 资源说明
目前所有资源均通过代码动态生成：
1. 像素字体 - PixelFontRenderer类
2. 角色立绘 - CharacterSpriteGenerator类
3. 背景 - BackgroundGenerator类
4. UI元素 - UIElementGenerator类

## 资源特点
- 纯像素风格设计
- 复古游戏美学
- 完全程序化生成，无需外部资源文件
